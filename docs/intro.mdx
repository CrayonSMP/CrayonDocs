# CrayonSMP
## A Collaborative Sandbox SMP

CrayonSMP is a private, application-based SMP where every single player directly shapes the world. No empty promises—we give you the actual tools to build the game alongside us.

## How it works

Instead of just playing passively, you can actively contribute your own content to the server:

- **Artists:** Use our web editor to design custom items, blocks, and furniture with zero friction.
- **Developers:** Write your own custom plugins, mechanics, and systems using **CraftEngine** to push vanilla survival to its absolute limits.
- **World-Builders:** Integrate custom structures and biomes straight into the world generation.

:::info

Everything you add must fit into a survival-friendly, balanced environment. We love immersive, custom-coded features—like custom-coded Waystones inspired by mods—rather than lazy `/warp` commands.

:::
